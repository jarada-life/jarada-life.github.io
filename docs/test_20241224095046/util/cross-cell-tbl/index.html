교차 셀 표 변환기

사용법: 1. 셀 병합은 다음 기호를 사용합니다: - ^ : 위쪽 셀과 병합 (rowspan) - < : 왼쪽 셀과 병합 (colspan) 2. 각 셀은 | 로 구분합니다. 예시 입력: | 머리 | < | 2cm | 4 | | ^ | 날개뼈 | - | 3 | 결과: ┌────────┬───┬──┐ │ 머리 │ 2cm │ 4 │ │ ┌────┼───┼──┤ │ │ 날개뼈 │ - │ 3 │ └───┴────┴───┴──┘
