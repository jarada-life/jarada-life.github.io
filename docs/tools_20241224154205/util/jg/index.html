타오바오 구매내역 추출 툴

타오바오 구매정보로 배대지 임포트용 엑셀파일을 생성하는 툴입니다.

사용방법

1. 타오바오 구매내역 페이지로 이동합니다 : 이동하기

2. 페이지 번역(대상언어:영문)을 수행합니다.

3. 알리프라이스 애드온을 설치합니다. (트래킹 정보를 얻기 위해 필요합니다. )다운로드 받기

4. 구매페이지에서 물류정보 on을 놓고, 추출하고 싶은 상품까지 느리게 스크롤합니다.

5. 전체복사(ctrl+A, ctrl+c)를 합니다.

6. 이 창에 돌아와서, 아래 입력란에 붙여넣기(ctrl+v) 합니다.

7. 다음을 선택하여 안내하는대로 수행합니다.

8. 마지막 페이지에서 다운로드가 가능합니다..

참고

1. PC버전 크롬에서 동작하도록 만들어졌습니다. 모바일 버전은 지원 계획이 없습니다.

2. 이 툴은 서버로 정보를 보내는 기능이 없습니다. 모든 변환은 브라우저 상(로컬PC)에서 동작합니다.

3. 개인정보 역시 사용중이신 브라우저에만 저장이 되니 무시하셔도 됩니다. 찝찝하시면 브라우저 캐시 날리시면 지워집니다.

4. 문제가 생길 경우 메일로 문의 부탁합니다.

입력

전체페이지를 복사해서 붙여넣으세요.

통관정보 입력

통관정보를 입력하세요.

다운로드

버튼을 선택하세요.
